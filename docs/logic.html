smabo — アプリ・ロジック仕様

smabo の顔・センサ・音声アプリ (Flutter)。本書は実装されている動作ロジックの要約です。
概要 通信 メッセージ 顔 音声 センサ オーバーレイ

1. 概要・設計スタンス

  • スマホをロボットの「顔」にしつつ、センサ送信（IMU・GPS・カメラ）と音声インタフェースを担う。
  • 走行・サーボの操作と ESP32 の設定は smabo-web が担当する（アプリには無い）。
  • ROS ランタイム/ライブラリは未使用。通信は素の WebSocket + JSON のみ。JSON の形を rosbridge v2.0 互換に整形し、smabo-brain（WebSocket 中継）と smabo-brain-ros（rosbridge_suite）のどちらにも接続できる立て付け。
  • ROS 互換の知識は lib/core/wire/ros_compat.dart 一箇所に隔離。転送層 ws_client.dart (WsClient) は ROS 非依存。

2. 通信構成（brain のみ）

エンドポイント役割送受信
brain
ws://smabo-brain.local:9090（既定）		 顔・音声・センサ・カメラのシグナリング 送: /imu/data, /gps/fix, /speech/audio, /webrtc/offer, /webrtc/app_ice
受: /look_at, /expression, /speech/say, /webrtc/answer
  • 送信トピックには送信元 prefix /app を付ける（brain が剥がして再配信）。
  • subscribe op は /look_at・/expression について送信する。
  • カメラ映像は WebSocket ではなく WebRTC で brain に送る（シグナリングのみ WebSocket）。
  • WsClient は自動再接続（バックオフ 0.5→8s）。channel.ready 確定で初めて connected 判定 → 接続/切断の通知が正確（フラップ防止）。
  • 接続/切断時に画面下にスナックバー通知。

4. 顔（目）

描画（EyePainter）

  • 白目（真円）＋虹彩（外）＋瞳孔（内）＋ハイライトの構成。各要素は色または画像。
  • 瞬き＝上から背景色（＝瞼）が降りて目を覆う。背景画像にも追従。
  • 整合性：瞳孔 ≤ 虹彩 ≤ 白目 を強制（FaceConfig.clamped()）。
  • 瞳の可動域を再計算：maxOff = 白目半径 − 虹彩半径 で、視線移動でも白目から飛び出さない（＋円でクリップ）。

視線モード

  • ランダム：一定間隔でランダムな注視点へなめらかに移動。
  • 追従：/look_at の Pose を画面注視方向へ射影して追従。

ウェイク反応

  • 「smabo」検出で 虹彩の色だけ変化（サイズ不変）。検出を 1 パルスとして受け、約 2 秒保持。
  • 音声受付中は虹彩の色相を連続サイクル。
  • 画面復帰時の誤発火防止のため、生成時に現在の wakeCount をシード。

カスタマイズ（Face settings／横向き）

  • 顔画面の「Face settings」から遷移。左：ライブプレビュー／右：設定。
  • プレビューは実画面と同じアスペクト比の仮想キャンバスに描き FittedBox で縮小（WYSIWYG）。
  • 色は右ペイン内インラインで Wheel / RGB / HSV 指定、変更は即プレビュー反映。
  • サイズはスライダー＋テキスト両方。背景色＝瞼色。

5. 音声

  • 端末内の音声認識（speech_to_text）はウェイクワードの検出だけに使う。文字起こし（STT）は brain 側で行う。
  • ウェイク照合：ja ロケールでは「smabo」がカタカナ化されるため、 smabosumaboスマボ すまぼスマホすまほ のいずれかを含めば検出。
  • 検出後は認識を止め、発話を録音（record、16 kHz・モノラル PCM）。無音（RMS 600 以下）が 1.5 秒続いたら終了。
  • 録音を WAV にして base64 で /speech/audio へ送信 → brain が STT して /speech/recognized を smabo-web へ配信。
  • /speech/say 受信で TTS 読み上げ（設定で ON/OFF）・吹き出し表示（設定で ON/OFF）。同じ文の繰り返しは無視できる。
  • ON/OFF トグルあり。OFF 時は待受しない。
  • 手動フォールバック：顔をシングルタップで即録音開始。

6. センサ送信

センサ内容
IMU加速度・ジャイロ＋相補フィルタで姿勢推定 → quaternion。sensor_msgs/Imu をレート指定（既定 20 Hz）で送信。
GPS位置ストリーム → NavSatFix（共分散は水平精度から近似）。権限要求あり。
カメラWebRTC（flutter_webrtc）で brain へ送信。解像度 640×480（目安）。フロント/バック選択（既定フロント）。
  • 各センサは画面下のトグル（Voice / Camera / IMU / GPS）で ON/OFF。設定画面にライブプレビュー。

7. オーバーレイ自動非表示・設定画面

  • 上部ステータス（接続ドット・音声）／下部センサ・設定ボタン／顔の設定ボタンは 一定時間後に自動非表示（既定 5 秒、設定で変更可）。ダブルタップで再表示（単発操作で勝手に出ない）。
  • 設定画面は縦向き（他は横向き）。最上部に目次（クリックでジャンプ）。
  • 言語は選択式（TTS/STT ロケール）。UI は英語表記。
